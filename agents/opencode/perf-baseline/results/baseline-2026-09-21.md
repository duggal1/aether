# Performance baseline — 2026-09-21

Purpose: frozen reference for future before/after comparisons. All numbers
from the release build containing: WebKit-exclusive engine, publish-on-change,
prewarm at creation, reclaim-on-suspend/sweep, bounded snapshots (`limit`),
run-stable store UUIDs. No content blocking (no socket API yet).

Env: macOS 27.0, arm64, Xcode 27 SDK (WKJSHandle/WKDOMNodeSnapshot present,
not adopted). Home network. Daemon: `.build/release/browserd --socket`,
one context, sequential page-opens unless noted. wall = CLI round trip
(create + navigate + didFinish). load = page `loadEventEnd`. fcp =
`first-contentful-paint`. docB = navigation `transferSize`.

## Variance warnings (reproduced, do not average away)

- youtube.com wall: 1.4s / 3.5s / 5.2s / 6.6s / 9.5s / 14.8s across runs,
  wall tracks the page's own loadEventEnd every time (same ~97KB doc).
- Fresh-profile first youtube load: 37s load event (cold process + uncached
  bundles + site JS), then 5–8s.
- notion/chatgpt/duckduckgo swing 2–6s run to run.
- Report median/p95/worst, never a single mean.

nohup .build/release/browserd --socket /tmp/x.sock --no-auth &
.build/release/browserctl --socket /tmp/x.sock context-create base
