# Browser comparison — time to tab title, 2026-09-21

Metric: milliseconds from navigation commit to the tab showing the real
page title (200ms poll). Aether measured in-app via verification harness
(`titleMilliseconds`); Safari 27.0 and Chrome 153 via AppleScript title poll.
Warm profiles, home network, one trial per cell except Aether (single run).

| Site | Aether | Safari 27 | Chrome 153 |
|---|---|---|---|
| apple.com | 637 | 526 | 1002 |
| youtube.com | 1530 | 490 | 1107 |
| wikipedia WebKit | 1374 | 1028 | 1371 |

Aether UI navigation now returns at `didCommit` (was: full `load`); tab
freshness flows through the publish-on-change stream.

Caveats: single-trial browser cells (YouTube alone swings 1–15s run to run,
so the 490 vs 1530 gap is not a ranking); different cache states; Chrome
runs Blink, the others WebKit 625.1.29 (Aether links the system framework,
verified via otool — no bundled engine).
